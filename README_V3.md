# IDTEWS v3.0 Professional Edition

## New in Version 3
- Professional Student Performance Profile page
- Latest saved student result presented as a profile card
- Risk status, confidence and academic indicators in one view
- Improved navigation with Student Profile module
- Existing advanced features retained: Dashboard, History, Search, Alerts, CSV persistence, User Management and Settings

## Run
```cmd
pip install -r requirements.txt
python setup.py
python main.py
```

Default admin login: `admin` / `admin123`.
